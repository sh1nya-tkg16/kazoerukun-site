かぞえるくん プライバシーポリシー

ProcessRidge（個人開発者、日本。以下「運営者」）は、スマートフォンアプリ「かぞえるくん」（Android / iOS。以下「本アプリ」）における情報の取り扱いを、次のとおり定めます。

先に結論（何がどこへ行くか）

  • 写真、APIキー、数えた結果、個人情報は、運営者には送られません。運営者はサーバー、データベース、アカウントを持たないため、運営者がそれらを見ることはできません。
  • 数えるとき、あなたの端末から Google の Gemini API へ直接 、縮小した写真・数える対象の名前・APIキーが送られます。Google 側の取り扱いは Google の規約とプライバシーポリシーに従います。
  • APIキーなどの設定は あなたの端末の中にだけ 保存されます。設定画面からいつでも削除できます。
  • 月額プランを契約すると、契約状態の確認のために、ストア（Google Play / App Store）と契約管理サービス RevenueCat が、匿名の利用者IDと購入の記録を取り扱います。氏名や支払い情報は運営者にも RevenueCat にも送られません。

1. 収集する情報

運営者は、本アプリを通じて、利用者の写真、APIキー、数えた結果、氏名・メールアドレスなどの個人情報を収集しません（受け取る仕組みがありません）。

本アプリには、アカウント、ログイン、クッキー、広告、アクセス解析（Analytics）、クラッシュレポート、広告目的の追跡はありません（本ポリシー制定時点の版）。月額プランの契約状態の確認にだけ、第三者のサービス（RevenueCat。下の「3-2」）を使います。

2. 端末内にだけ保存する情報

次の情報は、利用者の端末の中にだけ保存され、運営者には送られません。

情報 保存の目的 保存の方法・削除
APIキー（アプリ内では「チケット」と表示） 数える処理で Google の Gemini API を呼び出すため Android は flutter_secure_storage（EncryptedSharedPreferences 相当）、iOS は Keychain に保存します。端末のバックアップ対象外です。設定画面からいつでも削除できます。
今月の解析回数（年月と回数） 今月の利用回数を表示するため 端末内に保存します。アプリのデータを消去するか、アプリを削除すると消えます。
初期設定の途中経過 初期設定を中断しても続きから再開するため 端末内に保存します。アプリのデータを消去するか、アプリを削除すると消えます。

「APIキー」とは、利用者ご自身が Google AI Studio で発行する Gemini API の鍵です。本アプリでは「チケット（APIキー）」と呼んでいます。

3. 外部へ送信する情報

3-1. Google（数えるとき）

利用者が「数える」を実行すると、本アプリは利用者の端末から Google の Gemini API（generativelanguage.googleapis.com）へ、次の内容を直接送信します。運営者のサーバーは経由しません。

  • 利用者が選んだ写真（撮影またはアルバムから。縮小したもの）
  • 数える対象の名前（利用者が入力した文字）
  • APIキー（利用者ご自身が発行したもの）

Google から返ってきた結果（番号つきの枠）は、端末に表示されます。

Google 側での取り扱いは、Google の利用規約・プライバシーポリシーに従います。Gemini API の無料枠では、送信したデータが Google のサービス改善に使われることがあります（Google の説明による。出典：https://ai.google.dev/gemini-api/terms）。有料枠など、無料枠以外の場合の扱いは、上記の Google の規約でご確認ください。本アプリは、この点を初期設定の①で説明し、同意をいただいたうえでご利用いただく作りです。

運営者は、Google へ送信されたデータを見ることも、削除することもできません。

3-2. ストアと RevenueCat（月額プランを契約するとき）

月額プラン（月25枚まで／枚数の制限なし）の購入と更新・解約は、Google Play または App Store を通じて行われます。クレジットカード番号などの支払い情報はストアが取り扱い、運営者にも RevenueCat にも送られません。

契約状態（契約中かどうか、いつまでか）を確認するために、本アプリは契約管理サービス RevenueCat（RevenueCat, Inc.）の SDK を使います。RevenueCat のサーバーは、次の情報を取り扱います。

  • 本アプリが端末ごとに自動で付ける匿名の利用者ID（氏名やメールアドレスとは結びつきません）
  • ストアから受け取る購入の記録（商品、購入日、契約の期間、価格と通貨）
  • 端末の種類と OS のバージョン、アプリのバージョン

運営者は RevenueCat の管理画面で、匿名IDごとの契約状態と購入の記録を見ることができます。利用者が誰かは分かりません。RevenueCat 側の取り扱いは、RevenueCat のプライバシーポリシー（https://www.revenuecat.com/privacy）に従います。

月額プランを契約しない場合も、アプリの起動時に契約状態の確認（匿名IDの登録）が行われます。

4. 第三者への提供

運営者は利用者の情報を受け取らないため、第三者に提供することもありません。

利用者ご自身の操作で行われる次の場合は、運営者を介さずに行われます。

  • 数える処理のための Google への送信（上の「3」のとおり）
  • 結果を共有する機能（OS の共有画面）で、利用者が選んだアプリや相手に送る場合
  • 外部のページ（Google AI Studio など）を開く場合。開いたページでの情報の取り扱いは、そのページの運営者の規約・ポリシーに従います。
  • 月額プランの契約状態の確認のための、ストアと RevenueCat との通信（上の「3-2」のとおり）

本アプリが利用する外部ライブラリ（http、shared_preferences、flutter_secure_storage、image_picker、share_plus、url_launcher、gal）は、いずれも運営者へデータを送信しません。purchases_flutter（RevenueCat の SDK）は、上の「3-2」の情報を RevenueCat へ送信します。

権限 使う場面

6. 利用者の選択（削除、同意の撤回）

  • APIキーの削除：設定画面からいつでも削除できます。削除すると、本アプリから Google への送信はできなくなります（数える機能は使えなくなります）。
  • 端末内の他のデータの削除：端末の設定から本アプリのデータを消去するか、アプリを削除すると、解析回数と初期設定の途中経過も消えます。
  • 同意の撤回：Google への送信への同意は、APIキーを削除し、本アプリで数える操作を行わないことで撤回できます。すでに Google へ送信されたデータの扱いは、Google の規約に従います。Google に関する設定や削除の申請は、ご自身の Google アカウント・Google AI Studio 側で行ってください。
  • 写真の選択：どの写真を送るかは、利用者が毎回選びます。選ばなかった写真は送信されません。

7. お子様の利用

本アプリは18歳以上の方を対象としています（Google アカウントと APIキーの取得が必要なためです）。子ども向けのサービスではありません。
