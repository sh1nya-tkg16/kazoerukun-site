かぞえるくん サポート

写真に写った物を、Google の画像AI（Gemini）で数えるアプリです。ご自身の Google アカウントと Gemini API キーを使う作りで、運営者のサーバーは経由しません。

よくある質問

使うのにお金はかかりますか

  • アプリは月10枚まで無料で数えられます。月額プラン（月25枚まで 200円／枚数の制限なし 480円）があります。価格はストアの表示が優先されます。
  • 別に、Google の API キーの利用枠があります。無料枠の範囲で使う場合は、課金を有効にしていないプロジェクトのキーをお使いください。利用枠と料金は Google AI Studio でご確認ください。

月額プランの確認・解約はどこでしますか

  • iPhone：設定 → 一番上の自分の名前 → サブスクリプション。
  • Android：Google Play アプリ → 右上のアイコン → お支払いと定期購入 → 定期購入。
  • 解約しても、期間の終わりまでは使えます。アプリ内の「購入を復元する」は、機種変更や入れ直しのあとに使います。

APIキーはどこで取れますか

アプリの初期設定②に、画面つきの手順があります。Google AI Studio（https://aistudio.google.com/）で作成したキーを、アプリに貼り付けて「接続テスト」を押してください。

うまく数えられません

対象が重ならないように広げ、明るい場所で、真上から撮ってください。「赤い丸シール」のように具体的に書くほど正確です。アプリ内の「撮り方のコツ」もご覧ください。大切な数量は、実物と番号つきの枠を目でも確かめてください。

写真はどこへ送られますか

数えるときに、端末から Google の Gemini API へ直接送られます。運営者には送られません。くわしくはプライバシーポリシーをご覧ください。
